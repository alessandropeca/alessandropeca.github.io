Suffix Explanation

Column Name SuffixDescription
_mergedBest single value for this source, computed by weighted averaging (photometry) or priority selection (redshift, morphology). This is the column you should use for science.
_allJSON array of ALL values from every matched catalog for this source, e.g. [1.234, 1.237, 1.240]. Preserves full provenance — useful for checking agreement across surveys. Values are homogenized to the AGN-DB unit system, not reproduced in the units each catalog published: magnitudes are converted to AB, and the X-ray (xf*) and IR/radio (rf*) flux families are stored as log10, in the same units as their _merged counterparts (sections 5 and 10). The per-catalog decomposition is what _all preserves; _origin identifies which catalog each entry came from.
_originJSON array of integer catalog IDs (matching _all order), identifying which catalog contributed each value. Catalog ID mapping is in index2ds.pickle.
_sub_allJSON array of sub-classifications (morphology only), providing finer detail than the main class label.
e_Prefix indicating measurement uncertainty (error) on the quantity that follows. E.g., e_U_mag_merged is the error on U_mag_merged.

Missing Data

  • NaN (Not a Number) indicates no measurement is available.
  • Inside an e_*_all error-provenance array, the bare JSON token `null` appears in slots where the contributing catalog reported the value but no error for it (e.g., e_W1_mag_all = [null, null, null, 2.718]). Index alignment with the matching *_all and *_origin arrays is preserved. Parse with json.loads().

Identification & Coordinates

Column NameDescription
AGN-DB_IDStable integer source identifier
AGN-DB_nameUnique coordinate-based source identifier following the IAU designation convention (AGN-DB JHHMMSS.sss±DDMMSS.sss)
RARight Ascension (J2000) [degrees, 0–360]
DECDeclination (J2000) [degrees, -90 to +90]
pos_errorCombined positional uncertainty of the error-weighted mean position (RA, DEC), in arcseconds. For matched sources this is (sum of 1/sigma_i^2)^(-1/2) over the member entries; for single-catalog sources it is the input catalog's positional error. Input uncertainties that are missing or unphysical (NaN/inf/<=0) are replaced at ingestion with the median positional uncertainty of the valid entries of the same catalog (or, if a catalog has no valid entries, with its angular resolution).
originPython-tuple-repr string of catalog IDs that contributed to this source after LYRA cross-matching, e.g. "(21, 32, 81)". Parse with ast.literal_eval().
ra_allJSON array of the original per-catalog Right Ascensions (J2000, degrees) of the constituent entries, ordered by ascending catalog ID (same ordering as `origin`), e.g. [149.037269, 149.039382]. Together with dec_all this allows any association to be decomposed into its constituent catalog entries. Values rounded to 1e-6 deg (3.6 mas).
dec_allJSON array of the original per-catalog Declinations (J2000, degrees), same ordering and conventions as ra_all.
in_galactic_planeBoolean flag: True if the source lies within |b| < 10 degrees of the Galactic plane. Sources near the plane are more likely to suffer from stellar contamination, high extinction, and source confusion. Users building clean extragalactic samples should filter on in_galactic_plane == False.
galaxy_only_flagBoolean flag (stage 7.52): True when the source has at least one "galaxy" classification and NO AGN-type classification (type1, type2, generic_agn, blazar, lens_system, dual/merger) in any tier. These may be obscured/buried AGN where nuclear activity is undetected.
unknown_only_flagBoolean flag (stage 7.52): True when the source carries no usable classification — either every reported value across all five tiers is "unknown", or no tier reports any classification at all (2026-07-11 change; before that date the flag covered only the all-"unknown" case). The raw class arrays preserve the distinction: empty arrays mean nothing was reported, explicit "unknown" entries mean a catalog attempted a classification without reaching a conclusion.
star_flag

Categorical (stage 7.5). One of:

  • 'confirmed' — spec_class contains 'star' and no non-star spec_class. Spectroscopic star call; treat as definitive.
  • 'likely' — no spec_class, all non-spec classifications (SED/xray/image/gen) say 'star', and no X-ray detection in any xf*_all column. Photometric star call with no rescue signal. Caveat: a null X-ray flux can also mean no X-ray coverage at that position, not just a non-detection.
  • 'unlikely' — non-spec classifications all say 'star' BUT at least one xf*_all is non-null. The X-ray detection overrides the photometric star call, suggesting a misclassified AGN.
  • 'none' — not flagged as a star (any non-star classification in any tier, no classification at all, or every classification is 'unknown'). No rows are removed by stage 7.5.

Typical filters:

df.star_flag == 'none'# strict
df.star_flag != 'confirmed'# permissive
df.star_flag.isin(['none','unlikely'])# matches legacy behaviour
close_intra_dup_arcsecFloat (stage 7.53): separation in arcseconds to the nearest *intra-catalog* neighbor within 1.0", or NaN when none exists. Two merged sources are intra-catalog neighbors when at least one source-catalog contributed to both (set(origin_A) & set(origin_B) ≠ ∅). LYRA forbids merging two detections from the same catalog, so a small value here reflects a catalog-side data quality artifact, NOT a LYRA assignment failure. Typical filter for "trust this source is well isolated": df.close_intra_dup_arcsec.isna() | (df.close_intra_dup_arcsec > 0.1).
close_intra_dup_partnerInt64 nullable (stage 7.53): row index in this same table of the intra-catalog neighbor recorded in close_intra_dup_arcsec, or "NA". Use to inspect the counterpart directly: df.iloc[partner_idx].

Crossmatch Quality

Column NameDescription
match_quality_tierCategorical. Strength of the LYRA association: 'secure' — normalized posterior of the accepted hypothesis >= 0.9, or >= 0.5 for associations spanning >= 3 catalogs; 'reliable' — posterior >= 0.5, or >= 0.1 with >= 3 catalogs; 'possible' — all remaining accepted matches; 'unsure' — single-catalog source that entered at least one candidate association hypothesis that was evaluated and rejected; 'isolated' — single-catalog source with no such rejected hypothesis.
match_probabilityFloat in (0, 1]. P_match = O/(1+O), where O is the posterior odds of the accepted hypothesis. NaN for single-catalog sources.
match_probability_relativeFloat in (0, 1]. Relative probability P_rel of the accepted hypothesis, normalized over the conflicting hypotheses (those sharing at least one source) within its spatial group; the quantity on which the quality tiers are based. NaN for single-catalog sources.
astrometry_attachedBoolean. True when the match includes entries attached by the shared-astrometry (sub-mas) step.

Column NameDescription
best_Z_allBest redshift, selected by priority: 1st = spectroscopic (most reliable), 2nd = photometric, 3rd = generic. Stored as JSON array (first element is the best).

Classification

Label scheme

  • type1: Broad-line AGN (Seyfert 1, QSO Type 1, BLAGN)
  • type2: Narrow-line AGN (Seyfert 2, NLAGN, Sy1.5–1.9)
  • generic_agn: AGN without type specification
  • blazar: Blazars (BL Lac, FSRQ)
  • galaxy: Non-AGN galaxies (elliptical, spiral, starburst, etc.)
  • star: Stars, white dwarfs, CVs, X-ray binaries
  • lens_system: Gravitational lens systems
  • unknown: Unclassifiable or insufficient data
